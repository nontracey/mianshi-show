① 题目/知识检索searchQuestions
关键词 + 语义混合检索知识库，返回带来源的片段。治理链：manifest 漂移检查 → 审计落盘。

  


  

    
② 教练会话coachSession

    
代理一次教练问答。模型端点未配置时返回结构化错误——失败不静默，这本身就是演示点。

    
    
    
    
    
    

  


  

    
③ 对照组评测runEval

    
同一题集带工具/不带工具各跑一遍，输出功能/增益/安全三维分 + bad case + 置信度。runId 唯一，重复运行拒绝（证据不可静默改写）。

    
    
    
    

  


  
这套服务在治理什么

  

    
    
      
  • 超时 / 幂等重试：每个工具契约化（ToolContract），超时与重试次数不是参数是门禁；
    • 
      
  • 审计落盘可回放：每次调用追加写 data/audit.jsonl，重启不丢，可回放（replayFromFile）；
    • 
      
  • Skill 漂移检测：工具清单 sha256 版本化，内容变更未重扫即拒调（skill_drifted）；
    • 
      
  • 对照组评测：功能/增益/安全三维分 + bad case + 置信度分级 + runId 回滚；
    • 
      
  • 失败不静默：所有错误结构化返回（缺参 / 未配置 / 漂移各有明确 error 码）。
    • 
    

  


  
已知边界（先自己说）

  

    
    
      
  • 模型代理端点未接：② 返回 coach_not_configured；评测走确定性应答器，接真实模型后增益数字重测；
    • 
      
  • 黄金集 3 条、来源自建对照集——样本小，不推导全领域准确率；
    • 
      
  • 多租户只做设计；审计日志本身未加密。
